# Projektscope — LearningByDoing

## Problem
Programmieren lernt man am besten durch Praxis, nicht durch Theorie. Ein strukturiertes Repository für praktische Übungsaufgaben fehlt.

## Lösung
Ein Lern-Repository mit praktischen Übungsaufgaben in verschiedenen Programmiersprachen und Technologien, mit Fortschrittstracking.

## In Scope
- Übungsaufgaben in Python, Java, HTML/CSS/JS, React, SQL, TypeScript, Tailwind
- Strukturiertes Lernsystem (`LEARNING-SYSTEM/`)
- Fortschrittserfassung (`user_progress.json`)
- Implementierungsleitfaden (`IMPLEMENTIERUNG.md`)

## Out of Scope
- Automatisierte Bewertung von Lösungen
- Online-Lernplattform
- Zertifizierungen

## Ordnerstruktur
```
learningbydoing/
├── python/          # Python-Übungen
├── java/            # Java-Übungen
├── html-css-js/     # HTML/CSS/JS-Übungen
├── react/           # React-Übungen
├── sql/             # SQL-Übungen
├── typescript/      # TypeScript-Übungen
├── tailwind/        # Tailwind-Übungen
└── LEARNING-SYSTEM/ # Metadaten & Struktur
```
